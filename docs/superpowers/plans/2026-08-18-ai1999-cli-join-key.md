# kcap-cli join-key correlation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mint one opaque per-auth-run `join_id` in the CLI, stamp it on every `cli_*` event and on the two signup request bodies, and redirect the loopback closing page through kcap-web so the browser's PostHog identity bridges back into CLI telemetry.

**Architecture:** A process-static `SetupJoin` mints the key at `setup`/`login` command entry (before any funnel event, independent of which auth lane runs) and registers it as a `CliTelemetry` shared property. `LoopbackBrowser` gains an optional `ILoopbackJoin` collaborator: on a non-error callback it appends a `location.replace()` to today's closing page and hands listener ownership to a bounded background drain that waits for the browser's return hop at `/joined`, validates it field-by-field, and merges the web context into the shared property bag. Nothing in the auth path waits on any of it.

**Tech Stack:** .NET 10 NativeAOT, `System.Text.Json.Nodes`, `HttpListener`, TUnit, WireMock.Net.

**Spec:** `docs/superpowers/specs/2026-08-16-cli-web-event-correlation-design.md` — read the whole thing before Task 1; the sections that matter most per task are named in each task.

**Issue:** `kurrent-io/kcap-cli#574` / `AI-1999`. This plan covers the **kcap-cli slice only**. kcap-web and kcap-server are separate PRs in their own repos.

## Global Constraints

- **Wire vs property naming asymmetry — the single most likely thing to get wrong.** Both HTTP request bodies use `joinId` (camelCase). The PostHog property is `join_id` (snake_case). `CapacitorJsonContext` is globally `SnakeCaseLower`, so any DTO property needs an explicit `[JsonPropertyName("joinId")]` or it silently ships as `join_id` and kcap-web never sees it.
- **Key shape:** `Guid.NewGuid().ToString("N")` — 32 lowercase hex chars. Same minting discipline as `TelemetryDeviceId`.
- **The key is never written to disk, never logged, and never reused across runs.** In-memory only, one per auth attempt.
- **`KCAP_TELEMETRY_DEBUG=1` must print `"join_id":"[set]"`, never the value.** A placeholder rather than omission: the useful debug signal is whether the property is attached.
- **Opt-out is enforced at the mint.** `KCAP_TELEMETRY=0` / `DO_NOT_TRACK` / persisted opt-out / `KCAP_APP_SPAWN_NO_TELEMETRY` all collapse to `CliTelemetry.Enabled == false` → no key, no redirect, no `joinId` on any request, closing page byte-identical to today.
- **No telemetry path may ever throw.** An exception escaping to the NativeAOT runtime aborts the process (`Program.cs`). Every new method wraps its body in `try { } catch { }`, including the background drain.
- **`cli_auth_return` is emitted by the kcap-web Worker, not the CLI.** It must never be described as a sign-in event, and it must be added to the known-foreign list in the CLI's event-name collision test.
- **AOT:** never a JsonObject/JsonArray collection expression (`[a, b]` binds `Add<T>()`, which needs dynamic code). Use `new JsonObject { ... }` / `new JsonArray(a, b)`. After every task that touches `src/`, run `dotnet publish src/Capacitor.Cli/Capacitor.Cli.csproj -c Release 2>&1 | grep -E 'IL[23][01][0-9]{2}'` and expect no output.
- **Web-id character class:** `[A-Za-z0-9_-]`, length 1–64. This is a **privacy guarantee, deliberately fail-closed** — after the org form calls `identify(email)` the web `distinct_id` IS an email, and `@`/`.` are outside the class. Never relax it.
- **`site_variant` vocabulary:** exactly `legacy` or `redesign`. Absent is the common case (nobody has a `kcap_ab` cookie yet), not an edge case.
- **Loopback tests bind real `HttpListener`s on OS-assigned ports** and must carry `[NotInParallel]` — see the comment at `test/Capacitor.Cli.Tests.Unit/LoopbackBrowserTests.cs:6-9`.
- **Telemetry tests** must `CliTelemetry.Reset()` **and** `SetupJoin.Reset()` in `[Before(Test)]`, and carry the `[NotInParallel([...PathOverride keys])]` attribute copied from `SetupFunnelTests`.
- **README sync is a repo rule.** Task 7 is not optional and ships in this PR.

## Deviations from the spec, decided here

1. **Character-class check, not a regex.** The spec writes `^[A-Za-z0-9_-]{1,64}$`. A `foreach` over `char.IsAsciiLetterOrDigit` gives the identical guarantee with no regex engine in an AOT binary. Same semantics, asserted by the same tests.
2. **The cli-setup ping body is pinned by a pure builder + unit test, not WireMock.** `PingCliSetupAsync` constructs `new HttpClient()` inline and its 5s `Task.WhenAny` cap is deliberately tuned; making the client injectable to satisfy a WireMock test would restructure a timing-sensitive method for no extra assurance. The body string gets extracted into `internal static string CliSetupPingBody(...)` and asserted directly. `ProvisionAsync` **does** get a real WireMock body assertion, because its `HttpClient` is already injected.
3. **Mint placement is pinned by a source-guard test.** Proving "mints before `cli_setup_started` fires" by invoking `SetupCommand.HandleAsync` would run real filesystem and network work. A guard test that reads `SetupCommand.cs` and asserts the `SetupJoin.Mint()` offset precedes the `SetupFunnel.Started(` offset is the honest, cheap form — and the repo already has this idiom (`ReviewerModelVendorNeutralityGuardTests`).
4. **A mismatched `Accept` does NOT consume the single-use join; only a successful one does.** The spec is ambiguous here. Burning the join on a mismatch would let any local process kill the bridge by racing a junk GET to `/joined`, and there is no brute-force concern against a 128-bit key over a 15-second window.

```csharp
using Capacitor.Cli.Core.Auth;

namespace Capacitor.Cli.Core.Telemetry;

/// <summary>
/// The loopback browser's view of the join: build the first-hop URL for the closing page, and
/// accept whatever comes back at /joined. Kept as an interface so LoopbackBrowser stays dumb and
/// testable, and so a test can drive it without touching the process-wide statics in
/// <see cref="SetupJoin"/>.
/// </summary>
public interface ILoopbackJoin {
    string? FirstHopUrl(int port);
    void Accept(string query);
}

/// <summary>
/// One opaque correlation key per interactive auth run, published as a telemetry shared property
/// so every cli_* event for the run carries it. Bridges the CLI's device id to the browser's and
/// the server's PostHog identities at query time — nothing is stored and nothing is mapped.
///
/// <para><b>It grants nothing.</b> Not a credential, not a session, not a capability, and never
/// accepted as authentication by anything. That is what makes a leak not a breach — but it is the
/// bridge token, so it is never written to disk and never logged (see the redaction in
/// <see cref="CliTelemetry"/>'s debug renderer).</para>
///
/// <para>Minted only when telemetry is enabled, which collapses every opt-out route
/// (KCAP_TELEMETRY=0, DO_NOT_TRACK, the persisted flag, the app-spawn marker) into one check:
/// no key means no redirect and no joinId on any request, by construction rather than by four
/// separate guards.</para>
/// </summary>
public static class SetupJoin {
    static string? _current;
    static int     _consumed;

    /// <summary>The key for this run, or null when telemetry is off or nothing minted one.</summary>
    public static string? Current => _current;

    /// <summary>
    /// Mints the key and registers it as a telemetry shared property. Idempotent: a second call
    /// returns the existing key rather than rotating it mid-run. Returns null — and does nothing —
    /// when telemetry is disabled.
    /// </summary>
    public static string? Mint() {
        try {
            if (!CliTelemetry.Enabled) return null;
            if (_current is not null) return _current;

            _current = Guid.NewGuid().ToString("N");
            CliTelemetry.AddSharedProperty("join_id", _current);

            return _current;
        } catch {
            return null;
        }
    }

    /// <summary>
    /// Hop 1 of the return chain. Reuses <see cref="ProvisioningEndpoint.Url"/> so KCAP_SIGNUP_URL
    /// retargets it at a local miniflare for testing. <c>p</c> is a port integer, never a URL:
    /// the Worker builds the loopback URL itself, so accepting one here would be an open redirect
    /// on a production host.
    /// </summary>
    public static string? FirstHopUrl(int port) {
        try {
            return _current is null ? null : $"{ProvisioningEndpoint.Url}/api/cli/return?j={_current}&p={port}";
        } catch {
            return null;
        }
    }

    /// <summary>Filled in by Task 2.</summary>
    public static void Accept(string query) { }

    /// <summary>Test seam: restores the pristine, nothing-minted state.</summary>
    public static void Reset() {
        _current  = null;
        _consumed = 0;
    }

    /// <summary>The adapter handed to <c>LoopbackBrowser</c>; forwards to the statics above.</summary>
    public static ILoopbackJoin Loopback { get; } = new StaticLoopbackJoin();

    sealed class StaticLoopbackJoin : ILoopbackJoin {
        public string? FirstHopUrl(int port) => SetupJoin.FirstHopUrl(port);
        public void Accept(string query)     => SetupJoin.Accept(query);
    }
}
```

### Task 2: `SetupJoin.Accept` — the trust boundary

**Spec sections:** "`Accept` is the trust boundary" (the normative bullet list), "The value returned to the CLI is `$device_id`, never `distinct_id`", and the per-field independence table under Verification.

```csharp
    /// <summary>
    /// Validates and merges the context the browser hands back at /joined. This is the trust
    /// boundary: that request arrives over plain HTTP on loopback and is attacker-influenceable by
    /// ANY local process or web page that can cause a GET to the ephemeral port, so arrival proves
    /// nothing — only a key match does.
    ///
    /// <para>Field-by-field and independently, because one malformed field must never discard the
    /// others: <c>v</c> is optional and must be legacy|redesign (absent is the COMMON case — only
    /// visitors the experiment assigned have a kcap_ab cookie), and each web id must be
    /// [A-Za-z0-9_-] of length 1-64. That character class is a fail-closed privacy guarantee, not
    /// formatting: after the org form calls identify(email) the web distinct_id IS an email, and
    /// `@`/`.` are outside the class, so a future change that routed one here gets dropped rather
    /// than importing an identifier we promised never to collect.</para>
    ///
    /// <para>Exactly one call can ever succeed. A mismatch is dropped silently — nothing merged,
    /// nothing persisted, nothing sent, no error surfaced, and nothing in debug output, since the
    /// value is attacker-chosen. A mismatch deliberately does NOT consume the join: burning it
    /// would let any local process kill the bridge by racing a junk GET, and there is no
    /// brute-force concern against a 128-bit key over a 15-second window.</para>
    /// </summary>
    public static void Accept(string query) {
        try {
            if (_current is null) return;
            if (Volatile.Read(ref _consumed) != 0) return;

            var candidate = Param(query, "j");
            if (candidate is null || !KeyMatches(candidate)) return;

            if (Interlocked.Exchange(ref _consumed, 1) != 0) return;

            if (Param(query, "v") is { } variant && variant is "legacy" or "redesign")
                CliTelemetry.AddSharedProperty("site_variant", variant);

            if (Param(query, "w1") is { } capacitorId && IsWebId(capacitorId))
                CliTelemetry.AddSharedProperty("web_device_id_capacitor", capacitorId);

            if (Param(query, "w2") is { } wwwId && IsWebId(wwwId))
                CliTelemetry.AddSharedProperty("web_device_id_www", wwwId);
        } catch { }
    }

    // Constant-time so a timing signal can't leak the key to a local process probing /joined.
    static bool KeyMatches(string candidate) {
        var expected = _current;
        if (expected is null || candidate.Length != expected.Length) return false;

        return CryptographicOperations.FixedTimeEquals(
            Encoding.UTF8.GetBytes(candidate), Encoding.UTF8.GetBytes(expected));
    }

    // The [A-Za-z0-9_-]{1,64} guarantee as a character-class walk: identical semantics to the
    // spec's regex with no regex engine in an AOT binary.
    static bool IsWebId(string value) {
        if (value.Length is 0 or > 64) return false;

        foreach (var c in value)
            if (!char.IsAsciiLetterOrDigit(c) && c != '_' && c != '-') return false;

        return true;
    }

    // Four known fields, so a hand parse beats a dependency. Returns null when absent or empty.
    static string? Param(string query, string name) {
        foreach (var pair in query.TrimStart('?').Split('&')) {
            var eq = pair.IndexOf('=');
            if (eq <= 0) continue;
            if (!string.Equals(pair[..eq], name, StringComparison.Ordinal)) continue;

            var raw = pair[(eq + 1)..];

            return raw.Length == 0 ? null : Uri.UnescapeDataString(raw);
        }

        return null;
    }
```

```csharp
using System.Diagnostics;
using System.Net;
using System.Text;
using System.Text.Json;
using Capacitor.Cli.Core.Telemetry;
using Duende.IdentityModel.OidcClient.Browser;

namespace Capacitor.Cli.Core.Auth;

/// <summary>
/// OidcClient <see cref="IBrowser"/> backed by a 127.0.0.1 loopback HttpListener.
/// Opens the system browser to the authorize URL, waits for the redirect callback,
/// and returns its raw query string. WorkOS documents the loopback exception as
/// 127.0.0.1 (not localhost). The bind exception is intentionally NOT caught so the
/// GitHub flow can fall back to device flow on a bind failure.
///
/// <para>With an <see cref="ILoopbackJoin"/> the closing page also navigates the browser through
/// kcap-web and back to <c>/joined</c> on this same listener, which means the listener must
/// OUTLIVE <see cref="InvokeAsync"/>. That removes the `using var` safety net on every path, so
/// ownership is explicit: exactly one owner stops and disposes, exactly once, decided by an
/// <c>Interlocked.Exchange</c> on <see cref="_tornDown"/>. Handoff happens at exactly ONE point —
/// after a successful callback whose closing-page redirect was written. Every other exit
/// (timeout, cancellation, auth-error callback, an injected _openBrowser that throws, a
/// closing-page write that throws) retains ownership and disposes, matching today's behaviour.</para>
///
/// <para>The redirect fires on the same weak test the page itself uses (no <c>error=</c> in the
/// query). That is NOT an auth-success signal: the CSRF state check and the token exchange both
/// happen after this method returns. Nothing here is on the critical path — the token exchange
/// neither waits for the hops nor is affected by them.</para>
/// </summary>
public sealed class LoopbackBrowser(Action<string>? openBrowser = null, ILoopbackJoin? join = null)
        : IBrowser, IDisposable {
    readonly Action<string> _openBrowser = openBrowser ?? OpenSystemBrowser;
    readonly ILoopbackJoin? _join        = join;

    HttpListener? _listener;
    Task?         _drain;
    int           _tornDown;

    /// <summary>How long the background drain waits for the browser's /joined hop. Test seam.</summary>
    internal TimeSpan DrainCap { get; init; } = TimeSpan.FromSeconds(15);

    /// <summary>
    /// How long <see cref="Dispose"/> lets a pending drain finish before reclaiming the listener.
    /// Bounded so the short-lived `kcap login` doesn't hang, but non-zero so its browser's last hop
    /// finds a live port. Test seam.
    /// </summary>
    internal TimeSpan DisposeWait { get; init; } = TimeSpan.FromSeconds(3);

    public async Task<BrowserResult> InvokeAsync(BrowserOptions options, CancellationToken ct = default) {
        var port = new Uri(options.EndUrl).Port;

        var listener = new HttpListener();
        listener.Prefixes.Add($"http://127.0.0.1:{port}/");
        listener.Start(); // bind failure propagates (HttpListenerException / PlatformNotSupportedException)
        _listener = listener;

        var handedOff = false;

        try {
            await Console.Out.WriteLineAsync("Opening browser for authentication...");
            await Console.Out.WriteLineAsync($"  If the browser doesn't open, visit: {options.StartUrl}");
            _openBrowser(options.StartUrl);

            using var cts = CancellationTokenSource.CreateLinkedTokenSource(ct);
            cts.CancelAfter(options.Timeout);

            HttpListenerContext context;

            while (true) {
                var getContext = listener.GetContextAsync();

                try {
                    context = await getContext.WaitAsync(cts.Token);
                } catch (OperationCanceledException) {
                    listener.Stop();
                    Observe(getContext);

                    return new BrowserResult { ResultType = BrowserResultType.Timeout };
                }

                if (context.Request.Url?.AbsolutePath == "/callback") break;

                // Ignore favicon and other browser-issued requests that aren't our callback.
                context.Response.StatusCode = 404;
                context.Response.Close();
            }

            var query    = context.Request.Url?.Query ?? "";
            var success  = !query.Contains("error=");
            var firstHop = success ? SafeFirstHop(port) : null;

            // Armed BEFORE the response completes: /joined arriving before this method returns is
            // implausible in practice but must be safe.
            if (firstHop is not null) _drain = Task.Run(DrainAsync, CancellationToken.None);

            await WritePageAsync(context, success, redirectTo: firstHop, joined: false);

            // Handoff only after a clean write. A write that throws keeps ownership here, and the
            // finally below stops the listener — which breaks the drain's pending accept.
            handedOff = firstHop is not null;
            if (!handedOff) listener.Stop();

            return new BrowserResult { ResultType = BrowserResultType.Success, Response = query };
        } finally {
            if (!handedOff) TearDown();
        }
    }

    /// <summary>
    /// Waits for the browser's return hop, hands its query to the join, and serves the same page.
    /// Never throws: an exception escaping to the NativeAOT runtime aborts the process.
    /// </summary>
    async Task DrainAsync() {
        var listener = _listener;
        if (listener is null) return;

        try {
            using var cts = new CancellationTokenSource(DrainCap);

            while (true) {
                var getContext = listener.GetContextAsync();
                HttpListenerContext ctx;

                try {
                    ctx = await getContext.WaitAsync(cts.Token);
                } catch (Exception) {
                    Observe(getContext);

                    return;
                }

                if (ctx.Request.Url?.AbsolutePath == "/joined") {
                    try { _join?.Accept(ctx.Request.Url?.Query ?? ""); } catch { }
                    try { await WritePageAsync(ctx, success: true, redirectTo: null, joined: true); } catch { }

                    return;
                }

                // Same discipline as /callback's loop: a favicon request is not the return hop.
                try {
                    ctx.Response.StatusCode = 404;
                    ctx.Response.Close();
                } catch { }
            }
        } catch { } finally {
            TearDown();
        }
    }

    /// <summary>
    /// Called by whoever constructed this browser, at the end of their auth flow. Gives a pending
    /// drain a bounded window to finish, then reclaims the listener by stopping it — which cancels
    /// the drain's pending accept rather than abandoning a task that keeps the port alive.
    /// Idempotent. For `kcap setup` the drain finished minutes earlier (the user is at an
    /// interactive prompt), so the wait is instant.
    /// </summary>
    public void Dispose() {
        var drain = _drain;

        try { drain?.Wait(DisposeWait); } catch { }
        TearDown();
        try { drain?.Wait(DisposeWait); } catch { }
    }

    // The single teardown. Both the drain and Dispose attempt the transition; only the winner
    // tears down, so the listener is stopped and disposed exactly once on every path.
    void TearDown() {
        if (Interlocked.Exchange(ref _tornDown, 1) != 0) return;

        try { _listener?.Stop(); } catch { }
        try { _listener?.Close(); } catch { }
    }

    // A faulted accept task with no continuation is an unobserved exception; preserve the
    // discipline the timeout path has always had, for the drain's accept too.
    static void Observe(Task<HttpListenerContext> accept) =>
        _ = accept.ContinueWith(t => _ = t.Exception, CancellationToken.None,
            TaskContinuationOptions.ExecuteSynchronously, TaskScheduler.Default);

    string? SafeFirstHop(int port) {
        try {
            return _join?.FirstHopUrl(port);
        } catch {
            return null;
        }
    }

    static void OpenSystemBrowser(string url) {
        try {
            Process.Start(new ProcessStartInfo(url) { UseShellExecute = true });
        } catch {
            // Best-effort — headless environments (devcontainers, SSH) have no browser.
        }
    }

    /// <summary>
    /// The closing page, and the identical page served at /joined.
    /// <para><c>Referrer-Policy: no-referrer</c> is a SECURITY control here, not hygiene: this
    /// URL's query carries the OAuth <c>code=</c> and <c>state=</c>, and a browser configured with
    /// <c>unsafe-url</c> would otherwise put the authorization code into <c>Referer</c> on the
    /// cross-origin hop — i.e. into our own Worker access logs. <c>Cache-Control: no-store</c>
    /// keeps the join key and the web device ids out of the disk cache, and the /joined page's
    /// <c>history.replaceState</c> keeps them out of browser history.</para>
    /// <para>A JS <c>location.replace</c> rather than a 302: the person reads "Authentication
    /// successful!" FIRST, a no-JS browser simply stays on it, and a top-level GET navigation is
    /// what makes SameSite=Lax cookies travel (an img beacon or fetch would not).</para>
    /// </summary>
    static async Task WritePageAsync(HttpListenerContext ctx, bool success, string? redirectTo, bool joined) {
        var (title, message) = success
            ? ("Authentication successful!", "You can close this window and return to the terminal.")
            : ("Authentication failed", "Return to the terminal for details.");

        // JsonEncodedText escapes `<`, `>`, `&` and quotes, so a </script> break-out or a
        // quote-escape out of the JS string literal is structurally impossible — and it needs no
        // reflection, so it stays AOT-clean.
        var script =
            redirectTo is not null ? $"<script>location.replace(\"{JsonEncodedText.Encode(redirectTo)}\")</script>"
            : joined               ? "<script>history.replaceState({}, \"\", \"/joined\")</script>"
            : "";

        var html = $"<html><body style='font-family:system-ui;max-width:480px;margin:80px auto;text-align:center'>"
          + $"<h2>{WebUtility.HtmlEncode(title)}</h2><p>{WebUtility.HtmlEncode(message)}</p>{script}</body></html>";

        var buffer = Encoding.UTF8.GetBytes(html);
        ctx.Response.ContentType     = "text/html";
        ctx.Response.ContentLength64 = buffer.Length;
        ctx.Response.AddHeader("Referrer-Policy", "no-referrer");
        ctx.Response.AddHeader("Cache-Control", "no-store");
        await ctx.Response.OutputStream.WriteAsync(buffer);
        ctx.Response.Close();
    }
}
```
